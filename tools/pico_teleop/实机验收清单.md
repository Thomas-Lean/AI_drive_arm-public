# 实机验收清单（操作者在场，物理急停在手边）

目标：真臂遥操作把 330 ml 瓶装水从桌面 A 点夹起放到 B 点，完成 1 次。
前提：仿真验收 11 项全过；臂上控制器 `d1t_arm_ctrl` 在跑（不带 `--sim`，操作者自己起）；
任一步出现非预期运动 → **松握把**；不停 → **物理急停**。

## 0. 准备

```bash
# 0.1 确认 上位机 不动别人的进程；臂前方清场（无人、无易倒物、水瓶在 A 点）
# 0.2 环境（注意 real 要给网卡；程序必须加 --real-ok）
source ~/miniforge3/bin/activate d1t-teleop && cd ~/AI_drive_arm
source deploy/env.sh real enp5s0
python3 -m d1t_sdk state         # mode / online / TCP 正常再继续

# 0.3 PICO 路由（PICO Wi-Fi 与臂有线同网段时必做，重启失效）：
ip route get <PICO IP>          # 应走 wlo1，不是就：
# sudo ip route add <PICO IP>/32 dev wlo1 src <wlo1 IP>
# TeleRobot 查看器与振动页面同仿真验收（--haptics-ip <wlo1 IP>）

# 0.4 起步：准备位 + 夹爪全开（真臂命令，一条一条发；折叠位上遥操作拒绝接合）
python3 -m d1t_sdk gripper 70
python3 -m d1t_sdk joint 0,-40,60,0,30,0
```

## 1. 低速空手遥操作 1 分钟

```bash
python3 tools/pico_teleop/pico_teleop.py --real-ok --max-vel 0.20 --grip-vel 60 --goto-vel 40 --calibrate --haptics-ip <wlo1 IP>
```

- 面朝基座 +X 站（与臂同向），先标定（沿 +X 推约 25 cm），再握把接管；平移上限 0.20 m/s，
  姿态转速上限 60°/s、手柄姿态低通 3 Hz（默认值）；此组参数实机手感已确认可用。
- 提示：大幅转腕时个别姿态逆解无解（臂不动、程序计「逆解失败」不报错）——
  手腕转回来即恢复，属已知行为，不算故障。
- A/B 回位：先在准备位按 A 试一次（应原地到位、短振），再在中部按 B 回折叠位、按 A 回来，
  回位速度 40 °/s（`--goto-vel 40`），途中按握把即停。
- 手感检查：接合不跳、脱开即停、甩手限速；1 分钟无异常再进第 2 步。

## 2. 夹空气（empty 通路）

- 空手压扳机到底：两短振、夹爪停在全闭附近，电流无异常 → 松扳机张开。

## 3. 夹水瓶（grasp 自动锁）

- 水瓶竖放 A 点，遥操作对准夹住：应自动锁（单次振、夹爪停住角不再压）。
- 另开一个终端观察 J6 电流/温度（角色 5，别与遥操作抢 index 3）：

```bash
source deploy/env.sh real enp5s0 '' 5
while true; do python3 -m d1t_sdk state | python3 -c "import json,sys; s=json.load(sys.stdin); print('J6', s['current_ma'][6], 'mA', s['temp_c'][6], '°C')"; sleep 2; done
```

- 判据：锁定后 J6 电流回落到几十 mA 量级、温度不持续上升；异常 → 松扳机。

## 4. 取放 1 次

- 夹稳后抬起 → 移到 B 点上方 → 下放 → 松扳机张开 → 抬臂离开。
- 完成 1 次即达标（实机终点）。

## 5. 收尾与异常处置

- 正常收尾：Ctrl-C（臂 HOLD 在当前姿态）；夹着物体时 `python3 -m d1t_sdk gripper 70` 松开。
- 软急停（如逆解卡死需停）：另一个终端（角色 5，别与遥操作抢 index 3）
  `source deploy/env.sh real enp5s0 '' 5 && python3 -m d1t_sdk estop`；恢复：
  同终端 `python3 -m d1t_sdk reset` 后重新起步。
- 记录：当次 `--log` jsonl 路径、电流温度几个数、成功与否；回报维护者。
