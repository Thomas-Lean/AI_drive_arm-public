# 仿真验收清单（戴头显，对 --sim 控制器）

目标：对 `--sim` 控制器（lo，假舵机）把 PICO 手柄遥操作 11 项全部过一遍（9–11 为 A/B 一键回位）。
工具说明与参数见本目录 `README.md`；每项记「过 / 不过 + 现象」，全过再进实机验收。

## 0. 准备（约 10 分钟）

```bash
# 0.1 上位机 上确认没有别人的控制器在跑（有非 --sim 的：停手，别动，先回报）
pgrep -af d1t_arm_ctrl          # 应无输出

# 0.2 终端 1：仿真控制器（看到「启动完成：IDLE」即就绪，放着别动）
bash deploy/sim_start.sh

# 0.3 终端 2：摆起步位（中部姿态，夹爪全开）
source ~/miniforge3/bin/activate d1t-teleop && cd ~/AI_drive_arm && source deploy/env.sh sim
python3 -m d1t_sdk joint 0,-40,60,0,30,0 && python3 -m d1t_sdk gripper 70
python3 -m d1t_sdk state        # mode 应为 HOLD，online 七个 True

# 0.4 接 PICO（细节见 tools/pico_probe/README.md §2–3）
ip -br addr                     # 记 wlo1 的 IP，下称 <IP>；PICO 连同一 Wi-Fi
ip route get <PICO IP>          # 应走 wlo1；走错网卡（臂有线同网段时）先加路由：
# sudo ip route add <PICO IP>/32 dev wlo1 src <IP>
# TeleRobot config.yaml 的 xr.host 改 <IP> 后：
source ~/miniforge3/bin/activate telerobot && cd ~/TeleRobot
python start.py --no-image --ip <IP>
# PICO 浏览器 https://<IP>:8012/dashboard → 信任证书 → 「进入 Pico XR 视图」→ 进 VR 会话

# 0.5（可选）终端 3：3D 画面
source deploy/env.sh sim '' '' viz && __NV_PRIME_RENDER_OFFLOAD=1 __GLX_VENDOR_LIBRARY_NAME=nvidia DISPLAY=:0 ~/.venvs/mujoco-3.14.0/bin/python tools/arm_viz/arm_viz.py
```

**振动**：手柄振动要在 TeleRobot 的 VR 页里接入振动脚本（本仓库不含，见 README 已知限制 1）。
接入后，启动 `pico_teleop`（§1）之后、进 VR 之前，先在 PICO 浏览器开 `https://<IP>:8000` 并信任证书
（证书复用，同一 IP 只需信任一次）。未接入时，下表各项里的「振」以终端打印的事件为准，不算失败。

## 1. 启动遥操作（终端 4）

```bash
source ~/miniforge3/bin/activate d1t-teleop && cd ~/AI_drive_arm && source deploy/env.sh sim
python3 tools/pico_teleop/pico_teleop.py --haptics-ip <IP> --calibrate
```

先做标定手势（见第 1 项），然后按住握把遥操作；**松握把 = 脱开（臂停在原地）**。
Ctrl-C 退出（臂 HOLD 保持在当前姿态）。每轮换 `--log` 文件名或看打印的默认路径。

## 2. 十一项检查

| # | 操作 | 预期 | 结果 |
|---|---|---|---|
| 1 | 标定：握住握把，手向**正前方**推约 20 cm 松开；程序打印偏角后进遥操作。然后手右移 / 前移 / 上移各一段 | 打印「推程水平偏角 θ°、修正 yaw −θ°」；右移→画面末端右移、前移→前移、上移→上移，无斜走、无镜像 | ☐ |
| 2 | 按握把接合→松开脱开；脱开后手换位置再接合 | 接合瞬间臂不跳（目标=当前 TCP）；脱开后臂不动；再接合仍不跳 | ☐ |
| 3 | 握住握把，扳机从松到压到底再松开（画面或 dashboard 看 gripper_mm） | 夹爪全开 ≈70 mm ↔ 全闭 ≈4 mm 全行程，速度均匀 | ☐ |
| 4 | 重启程序加 `--fake-grasp-at 31`，缓慢压扳机 | 闭到 31° 自动停住（锁定），手柄振一下（单次）；继续压扳机目标不再变 | ☐ |
| 5 | 第 4 项锁定后松扳机 | 解锁，夹爪随扳机张开 | ☐ |
| 6 | 去掉 `--fake-grasp-at` 重启，空手把扳机压到底 | 两短振（empty）；停在 ≈4 mm 不再压 | ☐ |
| 7 | 第 4 或 6 项进行中：关掉头显的浏览器页面（或关 PICO Wi-Fi 几秒） | ≤1 s 停流、臂保持不动；恢复后**先松握把再按**才重新接管（程序打印「断流」→「脱开·须先松握把」） | ☐ |
| 8 | 接合状态手快速甩动 | 臂速度被限住（0.25 m/s 上限），控制器无 fault，松手即停 | ☐ |
| 9 | 松开握把，按住 A 0.5 s；再按住 B 0.5 s（夹爪张开时） | A：短振一下，臂约数秒回到起步位；B：短振，腕部先回、再收臂到折叠位并保持。到位各短振一次 | ☐ |
| 10 | 折叠位上按握把；再按 A，走到一半按握把 | 折叠位接合被拒绝（两短振、打印「臂在折叠位，不接合」）；回准备位途中按握把立即停住，松开握把后再按 A 能走完 | ☐ |
| 11 | 扣住扳机关夹爪，按 B | 拒绝（两短振、打印「夹爪未张开」），臂不动 | ☐ |

## 3. 判定与记录

- 11 项全过 → 进 `实机验收清单.md`；任一项不过 → 记现象 + 保存当次 `--log` jsonl，
  回报维护者（振动若不振，按 §0 的降级办法记限制，并附 viewer.log 的 `d1t_haptics` 行）。
