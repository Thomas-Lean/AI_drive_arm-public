# Q8 零位分析：clearAngle() 实际发什么、改不改零位（P0.3-T2）

> **状态：✅ 已关闭（2026-10-28，依据 F26）**——Thomas 多次实机运行确认开机 clearAngle 不改变零点，实测部分取消；零点对齐与重力下垂亦不实测（Thomas 2026-10-28 决定，§00.6 第 18 条），以 PROJECT_DRAFT §9 风险登记收口。本文件保留为历史分析，其中 §4 第 3 条（开机 6 条 0x11 背靠背连发）仍是有效风险记录。
> 对应草案 §11 Q8（C 类摸底）：「零位：官方控制器启动时对 J0–J5 调用 `clearAngle()`（J6 不调），实际发的是哪条指令、改不改零位」。
> 依据：**臂上实际运行版本**（E3 拷贝件，`arm_onboard/as_deployed/` 两个 tar，以下行号均指拷贝件解压后路径）+ FashionStar 官方协议页 + F26（Thomas 口述）。未用 Mac 旧仓库原厂版作依据（但 2026-10-28 已核实两者 src/include 逐字节一致，见 docs/ASSETS.md §4）。

## 1. 结论（先读）

1. `clearAngle()` 实际发送 **指令 0x11（FSUS_CMD_CLEAR_ANGLE_MTURN = 17，"重置圈数"）**，不是设置原点指令。
2. **不改舵机零点**——已由 F26 关闭：静态证据（官方协议 0x11 ≠ 0x17「设置原点」+ 臂上源码）与 Thomas 多次实机运行经验（从未出现零点变化）一致。
3. 现控制器全程只用单圈指令（0x08 设角 / 0x0A 读角），单圈零位由舵机内部标定决定——**每次重启控制器不会改变零位**。
4. 但 0x11 的执行**无任何成功确认**（默认不回包，代码也不读应答），且存在两个失效条件（见 §4）。因结论 2 已由 F26 关闭，开机 0x11 是否实际生效不再影响本项目决策（控制通路只用单圈口径）。
5. 新发现（未进 FACTS，见 §6）：开机 6 条 0x11 **背靠背连发**，帧间无延时，违反官方指令间隔 ≥10 ms 建议（F14 同源风险）。

## 3. 0x11 的官方语义（FashionStar 通用协议页，2026-10-28 查证）

- 指令名「重置圈数」：**「通过指令重置舵机的圈数信息，将当前绝对位置的角度重新记录为当前角度。」**
- 官方示例：当前多圈角度 +489.9°，重置后读数为 +489.9° − 360° = **+129.9°**——即多圈累计折算回单圈区间，圈数计数归零；**物理位置与单圈角度读数不变**。
- 零位归属：协议另有 **0x17「设置原点」**（将当前位置设为舵机原点，改变标定零位）。0x11 与 0x17 是两条不同指令；0x11 不写标定零位。
- 断电记忆：协议页未说明圈数重置是否断电保存（有独立的"圈数重置/断电记忆"文档），本项目暂不依赖此行为。

## 4. 失效条件与风险（历史分析，部分仍有效）

1. **释放状态前提**：官方明确「重置圈数指令仅在舵机处于释放状态时有效。为确保正确执行，建议先下发停止指令，再执行重置圈数操作」。控制器 `main()` 在开机时**直接连发**，未先发 0x18 停止/释放——开机时刻舵机若处于加锁状态，6 条 0x11 可能全部无效。
2. **无成功确认**：0x11 属「可配置响应」指令，默认**不回包**（响应开关 data_id 33 默认 0x00）；且 C++ 库发送后不读应答。执行成败**无从得知**，静默失败。
3. **帧间无延时（仍有效的风险记录）**：`sendPack()` 逐字节写出后立即返回，6 条 0x11 背靠背。F14：官方建议指令间隔 ≥10 ms、6 ms 已见丢包（舵机接收 RAM 塞满）。开机连发可能部分丢失。
4. **对现控制通路无影响**：控制器其后只用 0x08/0x0A（单圈口径）。即便 0x11 全部失败，单圈角度照常工作——这也是该问题长期无人察觉的原因。
5. **对本项目的影响点**：P0.4 起用 0x16 数据监控时，回包里的 position（0.1°，u32）与 turns（i16）是**多圈口径**。若开机 0x11 未生效且某轴圈数非零，0x16 的 position 与 0x0A 单圈读数会出现 360° 整数倍差异——数据配对时仍须核对这一口径差（与 F26 不矛盾：零点不变 ≠ 圈数计数一定为零）。

## 5. J6 不调 clearAngle 的影响

J6（夹爪）开机从不重置圈数。若夹爪轴因大行程往复累计了圈数漂移，0x16 读数与单圈读数将长期存在 360° 倍数差。旧项目夹爪逻辑用 raw 单圈值（F6），未受影响；新项目若用 0x16 统一采样，须对 J6 单独核对。
