# 虚拟部署（无臂，本机闭环）

目标：编译控制器、用 `--sim` 假舵机跑起来，再用 SDK 读到状态。全程不碰真臂、不手敲 DDS URI。
fish 用户先敲 `bash`（`source`/`export` 语法 fish 不认）。

## 1. 装依赖（一次；已装的自动跳过）

```bash
bash deploy/setup_host.sh        # Cyclone DDS 0.10.2（C/C++ 源码装到 ~/opt，PREFIX 可改）+ pip 包
```

首次要从源码编译 Cyclone DDS（需能访问 GitHub），耗时取决于机器；已有 0.10.2 的机器每步都跳过。
macOS 只装 Python 包，Cyclone DDS 0.10.2 需自行从源码装到 `~/opt/cyclonedds-0.10.2`。

## 2. 编译控制器 + ctest

```bash
bash deploy/arm_install.sh       # Release 编译 + 4 组测试；ctest 全过即成
```

配置输出要有 `D1T DDS: ON`（无 DDS 时只能 `--fake-client`，SDK 连不上）。

## 3. 起 `--sim` 控制器（终端 1，前台）

```bash
bash deploy/sim_start.sh         # 同机 lo 单播、ParticipantIndex 0；Ctrl-C 退出
```

没编译过会先自动跑 arm_install。看到 `d1t_arm_ctrl v0.1.0`、`启动完成：IDLE`、
`DDS domain 0：收 rt/d1t/arm_cmd，发 rt/d1t/arm_state` 后停住即活着（空闲时不刷日志）。
仿真注入参数（丢包/坏帧/温度/多圈）直接跟在后面：`bash deploy/sim_start.sh --sim-drop 3:0.05`。

## 4. SDK 示例（终端 2）

```bash
source deploy/env.sh sim         # 设 CYCLONEDDS_URI / PYTHONPATH / LD_LIBRARY_PATH（SDK 角色自动 index 3）
python3 sdk/examples/01_read_state.py     # online 七个 True 即通
python3 sdk/examples/02_move_joints.py    # 关节运动到 [0,-40,60,0,30,0] 再回零
python3 sdk/examples/03_gripper.py        # 夹爪 70→45→20→70 mm
python3 sdk/examples/04_line_arc.py       # 末端直线 + 小圆弧
python3 sdk/examples/05_stream.py         # J0 ±5° 正弦流式约 10 s 后 HOLD
```

想同时看 3D 显示：另开终端 `source deploy/env.sh sim '' '' viz` 后按 `tools/arm_viz/README.md` 跑。

## 5. 出问题怎么办

| 现象 | 处置 |
|---|---|
| 编译报找不到 CycloneDDS-CXX | 重跑 `deploy/setup_host.sh` 看第 2/3 步是否成；装在自定义前缀给 `PREFIX=… bash deploy/arm_install.sh` |
| sim_start 说已有 d1t_arm_ctrl 在跑 | 同机只能一个控制器（都占 ParticipantIndex 0）；先结束旧的 |
| SDK 打「没收到 ArmState」 | 两个终端都要 `source deploy/env.sh sim`；`echo $CYCLONEDDS_URI` 对比 ParticipantIndex 不同（控制器 0、SDK 3） |
| 控制器启动后崩溃，报 `dds_write.c ... Assertion ... iox` | 加载了 ROS2 自带的另一版 DDS 库；`env.sh` 已把正确库路径放最前，确认是在 source 过 env.sh 的终端里跑的 |
| `ctest` 的 sim_quick 超时 | 机器负载高时偶发，重跑一次；持续超时看 `build/test_sim --quick` 输出 |
