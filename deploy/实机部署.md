# 实机部署（有臂）

目标：臂载计算机跑 `d1t_arm_ctrl`，上位机用 SDK 控臂；收尾恢复官方 4 服务。
用脚本，不手敲 DDS URI。臂上的细节与故障排查见 `arm_onboard/controller/README.md` §3/§6。

前提：上位机已按 `deploy/虚拟部署.md` §1–2 装好依赖并编译测试过（臂上编译用同一 arm_install.sh）；
两侧网络互通（同网段 192.168.123.0/24，`ping 192.168.123.100` 通）。**舵机固件须 V330**
（`deploy/舵机升级.md`；V311 不支持 0x16/0x18/0x19，控制器起不来）。

## 0. 首次部署必做：方向 / 零位检查

SDK 的关节角方向（`calib.sign`）与零位（`calib.offset_deg`）在 `sdk/arm_model/d1t.json`。
换臂或首次部署要复核：

1. `python3 -m d1t_sdk lock` 前先 `python3 sdk/examples/01_read_state.py`，
   手动把各轴摆到已知姿态，读 `q_deg` 方向是否与直觉一致（抬起为正/为负）。
2. 用米尺量 TCP 到基座参考点的距离，对照 `fk(当前 q_deg)["pos"]`；偏差大改 `offset_deg`。
3. 方向参数为本臂实测值、零位偏移待复核：FK/IK 的**绝对**精度按 ±1 cm 量级预期，
   相对运动（直线/圆弧形状）不受影响。

## 1. 臂上：源码上臂、编译、启动

上位机仓库根下，把控制器源码与脚本拷到臂上 `~/d1t`（只需 ssh + tar，臂上不用联网）：

```bash
tar czf - --exclude=build arm_onboard/controller deploy | ssh ubuntu@192.168.123.100 'mkdir -p ~/d1t && tar xzmf - -C ~/d1t'
```

臂载计算机上（`ssh ubuntu@192.168.123.100`）：

```bash
cd ~/d1t
bash deploy/arm_install.sh                          # 编译 + ctest（臂上出厂已有 ddscxx 在 /usr/local）
bash deploy/arm_start.sh <臂上网卡名> <上位机IP>      # 停官方 4 服务 → sudo 前台起控制器
#   例：bash deploy/arm_start.sh eth0 192.168.123.233 -v
```

网卡名臂上 `ip addr` 查（接上位机网线的那个）。脚本先停官方 4 服务（控制器启动自检要求
它们 inactive），再以 ParticipantIndex 0、单播 Peer 指向上位机启动；URI 内联给 sudo。
看到 `d1t_arm_ctrl v<版本号>`（与 CHANGELOG 最新版本一致）、ping 7/7、`启动完成：IDLE`、周期 seq 递增即成。
退出码 3 = 官方服务没停干净 → 重跑 arm_start.sh；MTURN → 见控制器 README §6。

## 2. 上位机：设环境、通信检查

```bash
source deploy/env.sh real <上位机网卡名>     # 对端默认臂 IP 192.168.123.100；SDK 角色 index 3
python3 sdk/examples/01_read_state.py        # mode=IDLE、q_deg 合理、online 七个 True
```

网卡名 = 本机接臂网线的网卡（`ip addr` 查；例 `enp5s0`）。
之后按 `sdk/实机验收清单.md` 走（其中 §0.2 臂上起控制器已由 `arm_start.sh`、§0.3 上位机手敲 URI
已由 `env.sh real` 取代，其余命令与判据照旧）。安全底线：动前摆位确认不碰桌面/自身；中止 = 发送端 Ctrl-C
（看门狗约 0.3 s 停臂），来不及按物理急停；`free_all` 臂会掉，先托住。

## 3. 收尾（回官方服务）

```bash
# 臂上（d1t_arm_ctrl 所在终端 Ctrl-C，或直接）：
cd ~/d1t && bash deploy/arm_restore.sh     # 停本控制器 → 等它交还串口 → 拉起官方 4 服务
```

4 行 `active` 即恢复完成。本项目只 stop 过官方服务、从未 disable，
不覆盖任何官方文件。想开机自动跑本控制器：可选 `deploy/d1t-arm-ctrl.service`（默认不装）。

## 4. 出问题怎么办

| 现象 | 处置 |
|---|---|
| arm_start 退出码 3 | 官方服务没停干净或有进程占串口：重跑 arm_start.sh；重启臂可清残留占用 |
| 启动报 MTURN | J0–J5 多圈超限（\|q\|≥180°）：重启臂（开机只自动清 J6），摆位后再起 |
| 上位机收不到状态 | 先 `ping 192.168.123.100`；通则核两侧：网卡名、Peer 互指、ParticipantIndex 臂 0 / 上位机 3（`echo $CYCLONEDDS_URI`） |
| SDK 打 NG 提示 reset | 控制器在 ESTOP/FAULT：`python3 -m d1t_sdk reset` 后再动 |
| HOLD_FAIL / TX_FAIL | 见控制器 README §6 对照表 |
