# vision_grasp 实机验收清单（约 40 分钟）

按顺序执行，每步达到完成标志再进行下一步。`<网卡>` 为上位机接臂的网卡名（`ip addr` 查看）。

## 0. 准备

1. **机械臂**：控制器已在臂上运行（`deploy/实机部署.md`）；首次部署先完成 `sdk/实机验收清单.md` 的方向检查。
2. **相机**：D435i 刚性固定在末端，USB 3 接上位机。
3. **标定板**：压平贴在硬背板上，放在工作台；用尺实测尺寸填入配置——
   ChArUco 填 `square_length_m`（格边）与 `marker_length_m`（标记边）；单 ArUco 填 `marker_length_m`（黑框外沿）。
4. **环境**（每个终端）：
   ```bash
   cd <仓库根>
   source deploy/env.sh real <网卡>
   python3 -m d1t_sdk state      # mode 为 IDLE/HOLD，online 七个 True
   ```
5. **YOLO 权重**：放入 `apps/vision_grasp/models/`（见 `models/README.md`）。

下文 `CFG=apps/vision_grasp/config/charuco.yaml`；使用单 ArUco 标记时改为 `apps/vision_grasp/config/default.yaml`。

**中止方式**（全程适用）：预览窗 `q` 或终端 Ctrl-C，控制器看门狗约 0.3 s 停臂；紧急情况按物理急停。
出现 `IDLE estop` 或 `motion refused: latched …` 时，确认现场安全后执行 `python3 -m d1t_sdk reset` 再继续。

## 1. 取景（不动臂）

```bash
python3 apps/vision_grasp/scripts/live_view.py
```

完成标志：画面 1280×720@30 稳定；标定板放在物体摆放区域时完整可见，标记边长 ≥ 60 px。

## 2. 示教点位（可选）

配置已自带 32 个采集点位。相机支架与本仓库不同、点位看不到标定板时重新示教：

```bash
python3 apps/vision_grasp/scripts/teach_poses.py --config $CFG --n 32
```

- 回车依次为：走准备位 → 失力 → 锁住并 2 s 后记录 → 失力 …；`u` 删上一个点，`q` 结束。
- **失力期间整臂无力矩，须托住小臂。**
- 点位覆盖 J0 左右、J5 正负两侧，标定板始终在画面内。启动时自动备份原配置为 `<配置>.bak-<时间>`。

## 3. 点位彩排

```bash
python3 apps/vision_grasp/scripts/pose_test.py --config $CFG --dwell 2
```

完成标志：全部点位走完无故障，每点 `hold drift` ≤ 1°。

## 4. 手眼标定

```bash
python3 apps/vision_grasp/handeye.py --config $CFG
```

- 完成标志：逐点采集后回安全位，输出含 `qualified`，保存 `config/hand_eye_charuco.npz`（单 ArUco 为 `hand_eye.npz`）。
- 个别点被拒收（标记不可见、采图时晃动）不影响结果；全部被拒时检查标定板可见性与光照。
- 未达 `qualified` 时检查标定板尺寸与平整度后重新采集。离线换解法重算：
  `python3 apps/vision_grasp/handeye.py --config $CFG --solve apps/vision_grasp/config/sessions/<时间>/samples.npz`

## 5. 检测核对（不动臂）

```bash
python3 apps/vision_grasp/yolo_detect.py --config $CFG
```

完成标志：目标出现检测框，`BAS` 行显示基座系坐标；同一物体放两个位置，坐标与卷尺实测相差 1–2 cm 内。
首次加载模型在 CPU 上需几十秒。

## 6. 抓取

```bash
python3 apps/vision_grasp/grasp_yolo.py --config $CFG --dry-run   # 预演，不动臂
python3 apps/vision_grasp/grasp_yolo.py --config $CFG             # 实抓
```

- 预演完成标志：稳定选中目标，日志输出 `Pregrasp …` 与 `Grasp … close XXmm`。
- 实抓：预览窗按 `g` → 预抓取 → 直线接近 → 闭爪（`Holding at the stopped angle: XXmm`）→ 原路退出回准备位；按 `q` 松爪回安全位并退出。
- 闭爪后未夹到或开度不稳定时自动开爪退出。
- 调整：开合方向差 90° 改 `grasp.open_axis: z`；深浅调 `grasp.grasp_offset_m`；固定位置偏差见 README「精度调整」。
- 连续多次抓取时留意夹爪温度：控制器 45 ℃ 降出力、50 ℃ 释放。

## 收尾

```bash
python3 -m d1t_sdk joint 0,-90,89,0,0,0   # 回安全位
```

标定结果与采集记录在 `apps/vision_grasp/config/`。更换相机支架、夹爪或重装相机后须重新标定。
