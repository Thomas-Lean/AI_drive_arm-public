# vision_grasp 调参说明

默认配置在下列条件下调定：D1-T（舵机固件 V330，控制器 0.1.5）、D435i 眼在手上（彩色 / 深度 1280×720）、
不透明桌面与底座同高、目标为百岁山 330 ml 瓶（躺放，瓶径 56.5 mm）、泡沫香蕉、椭球。换设备或物体时按本页对症调整。

## 1. 现象 → 调哪个参数

| 现象 | 先看日志 | 调整 |
|---|---|---|
| 抓取点整体偏前 / 偏后（固定方向） | `Grasp …: base xyz` 与实测物体中点之差 | `base_offset_m`，按稳定均值填，每次 1–2 mm 微调 |
| 桌面自校正修正后仍不为 0 | `correction … after` | 检查桌面是否与底座同高、是否透明；不同高填 `support_z_m` |
| 指尖碰桌面 / 抓得太浅 | `cloud_top_down … table_z`、`height` | `grasp_offset_m` 每次 ±0.005（调大 = 停得更高） |
| 夹爪合到上限也没碰到物体 | `jaw … cm` 与物体真实宽度 | 爪宽估大：调大 `gripper_close_margin_mm` |
| 下降时指尖压到物体顶上 | `j6 preclose` | 调大 `gripper_preclose_margin_mm`，或填 0 关闭预合拢 |
| 夹得松 / 紧 | 控制器日志 `J6 碰到即锁 … 目标锁定` | 夹紧量在控制器里（`config.hpp` 的 `kJ6ContactSqueezeDeg`，默认 2.5°），不在本应用 |
| 夹着重物回准备位时报 `Motion/settling timeout … max error Jn` | 报错行里的关节与误差 | 带载下沉：调大 `robot.arrival_tolerance_deg`（默认 3°） |
| 预抓取点处顿一下 / 太快 | `stream plan: … with the TCP at … m/s` | `linear_vel_mps`（经过预抓取点的速度约等于它） |
| 整体太慢 / 腕部保持时抖动、控制器重发保持指令 | `timing: …`、控制器日志 | 关节速度 `grasp_vel_dps`、`approach_vel_dps`，加速度 `robot.acc_dps2`；抖动多时先降加速度 |
| 物体框是橙色、不旋转 | `no mask` 提示 | 分割掩码缺失：换角度、补光，或换更贴切的类别文本 |

## 2. 参数取值依据

| 参数 | 默认 | 依据 |
|---|---|---|
| `gripper_close_margin_mm` | 8 mm | 闭口上限要略小于物体，保证一定碰到；碰到后由控制器锁住，夹紧力与该值无关 |
| `gripper_close_min_mm` | 15 mm | 防止测量偏小时对刚性物体一直合到底；停在下限 + 2 mm 以内判抓空 |
| `gripper_preclose_margin_mm` | 20 mm | 每边约 10 mm 空隙；15 mm（每边 7.5 mm）时实测出现夹不到瓶子 |
| `grasp_offset_m` | 0.040 m | 指尖长 50 mm，TCP 停在中心上方 40 mm = 指尖越过中心约 1 cm，指垫落在物体中线 |
| `arrival_tolerance_deg` | 3° | 夹 378 g 瓶回准备位时腕部实测低约 2°；1.8° 时会到位超时 |
| `settle_s` / `poll_s` | 0.3 s / 0.05 s | 只在准备位确认一次到位；流式轨迹末端已减速到停，抓取点不等稳定窗 |
| `linear_vel_mps` | 0.10 m/s | 预抓取点处只减速不停；实际经过速度见日志 `stream plan` |
| `grasp_vel_dps` / `approach_vel_dps` / `acc_dps2` | 70 °/s / 80 °/s / 200 °/s² | 控制器各轴上限 100 °/s；加速度 200 °/s² 下腕部偶有重发保持指令，未触发故障 |
| `table_self_correct_max_deg` | 10° | 本设备修正前桌面倾角约 2–6°（相机安装与手眼误差）；超过 10° 视为平面不可信 |

## 3. 实测参考

**单次抓取节拍**（上述默认参数，94 次连续抓取流程统计）：

| 段 | 中位 | 范围 |
|---|---|---|
| 去程（准备位 → 抓取点） | 2.50 s | 2.02–3.19 s |
| 闭爪（含锁定） | 3.33 s | 0.37–7.82 s |
| 回程（抓取点 → 准备位） | 2.67 s | 2.32–7.33 s |
| 合计 | 8.55 s | 5.06–13.65 s |

同条件下改用分段执行（`final_motion: joint`，每段到位停稳）的仿真合计约 13.3 s。

**夹爪碰到即锁**（控制器 0.1.5，四种物体均由电流判据触发，碰到后约 0.15 s 锁住）：

| 物体 | 触发电流 | 锁定时命令领先实测 |
|---|---|---|
| 百岁山 330 ml 瓶 | 183 mA | 2.9° |
| 泡沫香蕉 | 342 mA | 3.6° |
| 椭球 | 178 mA | 2.9° |
| 硬壳塑料瓶 | 237 mA | 3.1° |

**桌面自校正**：本设备修正前桌面平面偏低 21–29 mm、倾斜约 2–6°，对应水平定位偏差 20–35 mm；
修正后平面偏差 0 mm / 0°，剩余 x 方向约 2.5 mm 的固定偏差由 `base_offset_m` 补偿（该值与相机安装有关，每台设备各自测定）。
