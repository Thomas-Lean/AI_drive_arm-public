# 更新记录

## 1.1.0

需要控制器与 SDK ≥ 0.1.5（夹爪碰到即锁）。

- 新增抓取方式 `cloud_top_down`（默认）：掩码点云 + 桌面平面求物体中心，沿长轴修透视；开合方向垂直长轴；爪宽取中段到长轴的距离；闭口 = 爪宽 − 余量。
- 桌面自校正：用物体周围桌面反推并修正相机俯仰、横滚与竖直误差；环带剔除离群点，平面不可用时用本次运行的缓存平面。
- 流式连续轨迹（`final_motion: linear`）：预抓取点只减速不停，回程同样不停；夹爪预合拢与去程同步进行；到抓取点只判到位容差即闭爪。
- 连续测试：`r` 在准备位松开，抓空不退出；执行期间按 `q` 等回到准备位再退出。
- 画面中文化：状态横幅、按键提示、当前目标与图例；无中文字体时退回英文。执行期间窗口保持响应。
- 日志新增桌面自校正修正量、流式规划时长与每次抓取分段计时。
- 默认参数提速：抓取关节 70 °/s、回准备位 80 °/s、关节加速度 200 °/s²、直线段 0.10 m/s；到位容差 3°、稳定窗 0.3 s；预合拢余量 20 mm。
- 检测类别默认加入 `banana`。

## 1.0.0

首个发布版。

- 拖动示教：整臂失力拖动、锁住后记录，点位写回配置。
- 手眼标定：支持单 ArUco 与 ChArUco 两种标定板，自动质量评估，支持离线重算。
- 视觉检测：yoloe 开放词表，实时显示相机系与基座系坐标。
- 视觉抓取：`top_down` 竖直下抓与 `camera_ray` 视线进给两种方式；预抓取、直线接近、闭爪锁停住角、原路退出。
- 抓取点固定补偿 `base_offset_m`、支撑面高度 `support_z_m`、夹取深度 `grasp_offset_m` 可配置。
- 计算设备自动选择 GPU / CPU。
