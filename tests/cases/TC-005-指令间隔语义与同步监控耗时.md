- 目的 / 对应退出标准：§4.2 P0.4「10 ms 间隔按舵机还是按总线计、同步监控 7 个回包收齐耗时」；§11 Q4 关闭标准「每周期耗时统计（≥1000 周期）；得出可用控制频率」。本用例结果同时是 Q6（改波特率）决议的直接输入：默认「后置」；若预算显示不足，触发的是**进一步调查与审查方关卡评估**，不直接等于改波特率任务（§00.6 第 10 条，H5 修订）。间隔语义的厂家口径已有（F38：按总线计），本轮 A/B 为**实测验证**——实测与厂家口径矛盾时以实测记 FACTS 并交分析。
  - 方法说明（判定原理）：阶段 A 单舵机定频查询标定本机丢包门限 L；阶段 B 双舵机交替（同舵机间隔 ≈ 2×命令间隔）——与 A 对比得出间隔语义；阶段 C 同步监控（0x19+0x16 d=1，只读）测收齐 7 回包耗时。**结论分支**（H5，M-c 修订）：
    - A 在某实测间隔档出现 miss 上升、B 在相同实测发出间隔下 miss 显著更低（对应同舵机间隔约 2×）→ 按单舵机计
    - A、B 在相同实测发出间隔下 miss 率相当 → 按总线计
    - A、B 全部档位 0 miss → **门限未观察到 = 间隔语义不可辨识**，Q4 该子项记【不可辨识】不得关闭（M-c；是否加更密档位补测由关卡决定）
    - 数据混杂（坏帧/疑似迟到占比高）→ 「不可辨识」，如实记录交分析
  - 等回包窗口（v3，B3 裁定·二）：**阶段 A、B 均固定 20ms**（>20ms 才计 timeout，**单独登记为异常**——全量实测最大 14.4ms 的 1.4 倍，F41）；密集档位的实际发出间隔可能被拉宽，逐条如实记录、分析按实测发出间隔分箱（P2 本就如此规定）。
  - 观察目标（v3，B3 裁定 4，只登记不判失败）：**rtt 与前序发出间隔的关系**——每档按舵机输出 rtt 分布（中位/p95/max）与前序发出间隔中位，阶段末按前序发出间隔分箱（≤12ms 紧贴总线最小间隔 / >12ms）汇总；TC-004 数据（F41）：J6 前序间隔越小 rtt 越大（密集 ≈10ms 间隔 4.7–12.1ms vs 宽松 150ms+ 5.7–6.5ms），J5 宽松下亦双峰至 14.4ms（与前序间隔无关的舵机自身形态）。
  - 阶段 C 周期默认 25 ms：事务实测约 13–15 ms + 请求帧间总线空闲 ≥10 ms（F14），周期过短会既超期又违反间隔建议；实际请求起点间隔与超期次数全部记录（M5）。0x16 单舵机事务耗时以 V330 实测为准（F41 rtt 全量 3.6–14.4ms），阶段 C 同步事务耗时本轮首次实测。
