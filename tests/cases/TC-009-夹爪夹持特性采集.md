## 0. 目的

夹爪驱控分三层，TC-009 v2 为三层提供数据并验证旧阈值：

| 层 | 内容 | 判据来源 |
|---|---|---|
| ①接触检测（主判据） | 0x16 电流突升 + 角速度骤降，目标 ~0.1 s 内判定 | TC-009 采集（t_contact_I / t_stop） |
| ②夹持力 | 0x08 power 上限 | P 对照试次（6000/3000 vs 0=按保护阈值 12000 mW，F49/F36） |
| ③兜底 | 旧 grip_detect 位置分类 + not_moved + 超时 | 旧阈值来自百岁山最终方案（GRASP-GRIP-SETTING-20261027） |

- TC-008 两轮停住值 32.5 / 31.6（误差 +3.5 / +2.6）按旧阈值均判 grasped，与现场一致；33–34 窄窗
  作废（F57）。
- TC-009 重跑目的：**验证旧阈值在空夹 ×10 / 夹瓶 ×10 下能否把两类分开，并采集电流**。

## 1. 统一口径（Thomas 2026-11-03 确认）

1. 夹爪位置一律以**舵机角度（°）**控制和判定，mm 只作参考。
2. 指令范围 [-30, 64.5]（F7，fsbus JOINT_LIMITS）；张开 64.5、关闭目标 29.0；手拨机械极限
   −31.4 / 65.4 不是指令可达位置，不能作为判据。
3. 判定沿用旧 grip_detect：停住−目标 |≤1°| 为 empty，≥+2° 为 grasped，其余 uncertain；加
   not_moved 和超时。
4. 开跑先清 J6 多圈（k2）；7 轮原始多圈角度必须在 ±180 内（k）。
5. 开度以**金属指间距（mm）**为基准；垫面间距 = 金属指间距 − 4（两侧垫各约 2 mm，换算用，
   不实测）。中段参考式 间距 ≈ 0.85×角度 + 19.8；全开段（>50°）公式不准，以实测为准。

## 2. 安全 S1–S7（fsbus + tc008 + tc009 全部适用；selftest 逐条覆盖）

| 条 | 内容 |
|---|---|
| S1 开机检查 | preflight 读 7 轮 0x16 **原始多圈**（不做单圈归一化）：J0–J5 不在 ±180 → 拒绝退出；J6 不在 ±180 → 0x18 释放 → 0x11 清圈 → 读回 ±180 内才继续；所有轴 st 无保护位、角度在 F7 内。fsbus 新增 `read_raw_multiturn` / `clear_turns`（内部先发释放帧） |
| S2 方向试探 | J6 首次动作：朝目标方向走 5°、≤10°/s，读回确认**方向正确且位移达标**（步长 ≥4° 时 ≥3°；被限位截短时 ≥0.6×步长——T4b3 S1）；不满足 → 释放并中止 |
| S3 到位校验 | J6 每条 0x08 在 T+0.5 s 内读回：空载运动 \|读数−目标\|≤2°；夹物关闭=停稳且未超时，**停稳判据窗 [close_ms+0.2, close_ms+0.5]（T4b4：窗起点 +0.2 s 避开关闭收尾微动——v2 现场 051531 试次 11 旧窗含 32.3→32.0 收尾、极差 0.7 误判未过；复算 1.82 s 起已停稳 31.6–31.7，新窗 n=16 极差 0.1 判过）**；张开在 2.075 s 首检——未到位且未在动 → 立即释放（事故场景自首条 0x08 至释放 ≤2.3 s）。不满足 → 0x18 释放并中止 |
| S4 保持守卫 | J6 非夹持保持期间（张开、标定点、示教/放瓶等候、空夹试次）定时读 0x16：电流 >400 mA 持续 2 s → 释放（400 为**临时值**，待 TC-009 数据修订；实测健康夹持停稳 541–557 mA 高于此值，故夹持保持期间（tc008 与本用例夹瓶/拔笔试次）不套用，改温度 ≥55 ℃ → 正常中止。**此解释审查方 2026-11-03 审定**；夹持试次堵转兜底 = 时长硬上限 4 s/6 s 到点即张开并按 S3 校验） |
| S5 中止处置 | J6 状态不确定 → 0x18 释放；已验证张开 → 可保持；已验证夹持（tc008 的 M1）→ 保持 0x08→29 并打印温度；**除已验证夹持外，中止路径不给 J6 发 0x08** |
| S6 退出状态 | 退出前打印 J6 终态，只允许「已验证静止、未堵转」或「已释放」两种 |
| S7 温度门 | 每试开始前 J6 ≥55 ℃ 暂停等冷却（回车重测 / q 中止） |
