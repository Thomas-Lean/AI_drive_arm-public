## 采样率与判据（按 F45/F47 实测参数重算，写死可复算）

- 采样实现：0x16 优先（等待窗 **15ms** = 查询态 rtt ≈11ms + 余量，F47；失败用 0x0A 补采，CSV `src` 列区分）；对表 **12ms**（实测节奏，F45）。
- 预期采样率（计算：每周期 1 条 0x08 发送+间隔 ≈11ms，其余时间按 12ms/样本）：
  - **P100 段 ≈70Hz，约 7 样本/100ms 周期**；
  - **P50 段 ≈60Hz，约 3 样本/50ms 周期**；
  - 参考段/停后窗（无 0x08 穿插）≈83Hz（单舵机连续查询上限，F45）。
- P1 门槛（v5 调整，原「≥50Hz」作废）：**实测采样率 ≥40Hz 且 P100 ≥5 样本/周期、P50 ≥2 样本/周期**——P50 段每周期仅 ≈3 样本，对 50ms 重起锯齿的分辨力有限（每条重起的加减速段 ~25ms 内仅 1–2 样本），故 **P100 段为主判据、P50 段为辅助记录**；达不到门槛按偏离登记查原因，不据此判硬件失败。
- **判定判据（主，写死）**：速度纹波展宽比 `spread = (p95−p5)/mean`，计算方法=运动窗内（参考段 t_cmd→t_end；流式段 t_start→t_last）、剔换向点 ±0.2s、±3 样本中心差分且只在连续保留段内（H-f）。**阈值：spread <0.35 → 倾向连续；≥0.55 → 倾向每条从零速重起；0.35–0.55 → 不明确（交审查方关卡裁定）**。依据：fsbus_selftest S7/S8 离线仿真（理想匀速 0.00 vs 100ms 重起 0.55）+ 实机 0.1° 量化噪声在 12ms 采样间隔下的余量；阈值初值由执行方提出，审查方复核时可调。
- 辅助输出（一并进 SUMMARY，不单独判）：近零占比（v<0.2×指令速）、停后窗、静止窗均值。
- **辅助判据（口述）**：每轴流式结束后脚本询问 Thomas「1=连续 / 2=轻微顿挫 / 3=明显顿挫」，记录进日志与 SUMMARY。
