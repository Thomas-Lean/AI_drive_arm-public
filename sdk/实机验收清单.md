# d1t_sdk 实机验收清单（约 30 分钟）

> 交付物：`sdk/`（d1t_sdk 包 + examples + tests）。离线测试已全过；
> 本清单验的是「上臂能用」。命令全部原样可抄；占位符 `<HOST_IFACE>` 填上位机接臂网线的
> 网卡名（`ip addr` 查）、`<ARM_IFACE>` 填臂上接上位机的网卡名；fish 终端先 `bash`。

## 0. 准备（约 10 分钟）

1. **起始姿态**：臂默认停在折叠姿态起步。折叠位 J1/J2 会略超软限位（约 0.5°），
   控制器只报 warn OUT_OF_LIMIT，首个运动命令会被钳回限位内（不到 1° 的小跳），属正常。
2. **臂上起控制器**（控制器装在 `~/d1t`，安装见 `deploy/实机部署.md` §1；脚本会先停原服务）：
   ```bash
   cd ~/d1t && bash deploy/arm_start.sh <ARM_IFACE> <HOST_IP> -v
   ```
   `<ARM_IFACE>` 换成真实网卡名、`<HOST_IP>` 换成上位机 IP，**不能原样粘贴**（否则报
   `does not match an available interface`）。
3. **上位机装 SDK 依赖 + 设 URI**（fish 先 `bash`）：
   ```bash
   cd ~/AI_drive_arm && git pull && pip3 install --user cyclonedds==0.10.2 numpy
   source deploy/env.sh real <HOST_IFACE>
   cd ~/AI_drive_arm/sdk
   ```
4. **通信检查**（不过不往下走）：
   ```bash
   python3 examples/01_read_state.py
   ```
   通过判据：打印出 state（mode=IDLE、q_deg 7 轴合理）、online 七个 True。

## 0.5 方向检查（约 3 分钟，不过不往下走）

> 首次部署、换臂或重装舵机后必做；同一台臂做过一次即可。

方向错了，后面的 `move_j` / `move_l` 会往反方向冲，所以先单轴各走 +10° 看一眼。起始姿态 J3、J5 接近 0（手腕没扭）。

```bash
python3 - <<'EOF'
import sys; sys.path.insert(0, ".")
from d1t_sdk import D1Arm
look = ["J0 从上往下看逆时针（臂转向自己的左边）", "J1 大臂往前倾", "J2 小臂末端往下",
        "J3 从臂后方顺着小臂看，顺时针", "J4 手腕末端往下", "J5 从臂后方顺着小臂看，逆时针"]
arm = D1Arm()
try:
    for i in range(6):
        q = arm.state()["q_deg"]; t = list(q); t[i] += 10
        input(f"\n回车 → {look[i]}：")
        arm.move_joints(t, vel_dps=20); arm.wait_idle()
        input("看清了，回车回原位：")
        arm.move_joints(q, vel_dps=20); arm.wait_idle()
finally:
    arm.close()
EOF
```

通过判据：6 个轴的转向都和提示一致。任一轴反了 → Ctrl-C，记下轴号，**不做后面各项**，检查标定参数 sign。

## 1. 五项验收（每项一次，臂动作符合预期即过）

中止手段（全部适用）：发送端 Ctrl-C → 看门狗约 0.3 s 停臂；来不及按物理急停。

| # | 项 | 命令 | 预期 | 通过判据 |
|---|---|---|---|---|
| 1 | 关节运动 | `python3 examples/02_move_joints.py` | 先平滑走到 [0,−40,60,0,30,0]°，再 4 s 走到 home（URDF 全零，**臂前伸**，与原厂 HOME 姿势不同） | 动作平滑无顿挫、各轴到位（打印与目标一致）；**零位米尺**：停在 home 时，从底座底面中心量到两指中点，前伸 ≈351 mm、高 ≈426 mm（±10 mm；超差 = 零偏不为 0，记下数值，不阻断） |
| 2 | 夹爪开合 | `python3 examples/03_gripper.py` | 70→45→20→70 mm，J6 慢速（20°/s）开合 | 指间距目测与目标 mm 相符、速度明显慢于关节 |
| 3 | 直线 | `python3 examples/04_line_arc.py`（前半） | 末端走直线 ±8 cm 再回来 | 目视走直线（不绕弯）、到位打印与目标差 <1 cm |
| 4 | 圆弧 | `python3 examples/04_line_arc.py`（后半） | 末端走小圆弧（半径 5 cm）绕到旁边 | 目视走弧线、平滑 |
| 5 | 关节流式 | `python3 examples/05_stream.py` | J0 ±5° 正弦 0.25 Hz 约 10 s，然后 HOLD | 平滑无顿挫（出现顿挫即 NG） |

## 2. 应急与收尾

- 软急停：`python3 -m d1t_sdk estop`（恢复：`python3 -m d1t_sdk reset`）
- 失力（托住再用）：`python3 -m d1t_sdk free`；锁住：`python3 -m d1t_sdk lock`
- **下电前收臂**：`python3 -m d1t_sdk park`（先确认夹爪没夹东西并 `gripper 70` 张开；park 腕部回零→大小臂一起收回→停 0.5 s 失力，打印「已到折叠位并已失力，可以下电」后再断电；夹爪未张开会报错不动）
- 收尾（任一）：
  - 留在 SDK：`python3 -m d1t_sdk park`（结束时已失力；或 `lock` 保持）后 Ctrl-C 控制器；
  - 回原厂：臂上 Ctrl-C 控制器 → `sudo systemctl start marm_controller marm_communication marm_control marm_subscripber` → 4 个服务 active 即恢复。

## 2b. park 实机（下电收臂）

| 项 | 命令 | 预期 | 通过判据 |
|---|---|---|---|
| park | `python3 -m d1t_sdk park`（从前伸位、从 [0,−40,60,0,30,0] 各起一次，先 `gripper 70`） | 腕部回零→大小臂一起收回（各段打印用时）→停 0.5 s 全轴失力，打印「已到折叠位并已失力，可以下电」 | ① 全程**不碰桌面/自身**；② 失力前各轴到位 ≤3°（目标 q_deg ≈ [0, −90, 88.5, 0, 0, 0]）；③ 失力后臂靠在折叠位不明显下落，`python3 -m d1t_sdk state` 的 ctrl_state = RELEASED，记录失力前后角度差 |
| park 拒绝 | 夹爪夹住一个物体（如 `gripper 47` 夹 330 ml 瓶）后 `python3 -m d1t_sdk park` | 报错「夹爪未张开…确认没有夹东西后先 gripper 70」 | 臂与夹爪都不动，物体不掉 |

## 3. 已知差异（验收时留意）

- **home = URDF 全零（臂前伸）**，不是原厂 HOME [0,−90,89,0,0,0,0]。
- **FK/IK 绝对精度取决于零偏**：offset 默认 0，未做零位米尺时
  项 3/4 看的是「直线/圆弧形状与平滑度」，端点绝对位置 ±1 cm 量级即可。
- 夹爪 mm 为**金属指间距**；垫面间距 = 金属 − 4 mm。
